# JoeCoder Pro 20.1 — Architecture Transition Record

This filename is retained because governance verification cites it. The prior browser-lifecycle upgrade plan is historical and is preserved under `archive/legacy-browser-workflow/` with the retired client.

## Current authoritative architecture

- The durable Agent Job is the sole public execution abstraction.
- Folder selection starts a read-only inspection job.
- Ask and Plan remain read-only.
- Automatic accepts one ordinary-language objective and advances it through server-owned deterministic gates.
- The browser exposes conversation, read-only project navigation, Project Brain, settings, Joe Live, Stop, and Resume.
- Public Accept, Draft, Authorize, and Apply routes and controls are not compatibility surfaces.
- Internal lifecycle operations require the runtime process secret and current Agent Job identity.
- Mutation uses sealed scope, budgets, snapshots, path jail, atomic writes, verification, bounded correction, rollback, and evidence-derived terminal labels.
- Unsupported or skipped checks remain explicit limitations.

## Ratified limitations

The current implementation map is `plan/amendment-1.3.3/spec/implementation-map.json`. Every partial law must reference a named ratified limitation; a partial control is never counted as fully enforced. The user-visible list is in Models & settings under Governance truth and is summarized in `SUPPORTED_CAPABILITIES.md`.
