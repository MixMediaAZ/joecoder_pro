# Recovered Kernel Registry — Audit Only

This directory preserves the synthetic 51-entry registry that JoeCoder Pro 20.1 previously loaded as canonical.

It is not governing authority. Its own source note states that it was reconstructed because the original prospectus registry was considered missing. Fourteen `JC-KER-*` entries are generic placeholders and therefore cannot satisfy the ratified prohibition on placeholder or aspirational controls.

The governing canonical laws are the byte-preserved 48-law Plan 1.3.1 registry under `../../ratified-1.3.1/spec/rules.json`. Amendment 1.3.2 maps the current implementation to those laws without rewriting them.
